📖 玩法说明

• 自由模式：自选两名角色 1v1 对决
• 双人对战：两人各自翻牌抽卡，抽到什么用什么
• 大乱斗：任意数量角色混战，最后存活的获胜
• 手动对战：双摇杆亲自操作，手机触屏 / 电脑键盘都能玩，摇杆位置大小可自定义
• 三合一：自由/双人/大乱斗三种玩法一网打尽，设置中可开关
• 故事模式：闯关制故事地图，通关一关解锁下一关
• 每个角色拥有独特技能，战斗中自动释放
• 消灭对手全部角色即获得胜利

📜 游戏规则

  • 自由模式：手动选两个角色对战，自动弹跳，碰边反弹。
  • 双人对战：双方抽卡，玩家1下方，玩家2上方。
  • 大乱斗：自选2-5个角色混战，存活到最后获胜！
  • 🕹️ 手动对战：选自己和敌方的角色，由你亲自操作！左下摇杆控制走位，右下摇杆朝推动方向松开发射技能（冷却显示在摇杆上）；电脑自动隐藏摇杆，用 WASD/方向键移动、鼠标瞄准、左键或空格发射（冷却显示在角色脚下的环上）。触屏设备可在「设置→摇杆设置」里自定义摇杆位置和大小。
  • 王艳👩‍🏫：弯折腿🦵，冷却3秒，反弹3次，伤害30；副技能📱叫家长：每30秒拿出手机召唤2名家长👨👩（烟雾降临，随机位置），家长随机弹跳，碰到学生撞上扣10血，不会伤到王艳。
  • 李嘉泽😴：打鼾Z💤，冷却4秒，3个Z各15伤害。
  • 李晨雨👧：声波🌊，冷却5.5秒，伤害20，无法反弹可穿透；半血后被攻击20%把攻击者记上死亡笔记📓，反伤100。
  • 朱皓宇👦：豪车🚗/金表⌚，冷却4.5秒，随机28或20伤害。
  • 丁晓华👩‍💻：电脑💻，冷却7秒，时停3秒每秒18血。
  • 历史老师👩‍🏫：召唤讲解石🪨，冷却6秒，上限8个，讲解石近战伤22/血60。
  • 程梓鑫🧑‍🍳：牛肉饼🍔，冷却5秒，反弹5次消失，敌伤15，自回30。
  • 赵丽娜👩‍🏫：菠菜叶🥬，每秒发射，伤害5，死亡后满血复活一次。
  • 刘一鸣🧑‍🎓：鸡米花🍿，冷却3秒，伤害15，开局1秒后分身出刘二鸣、刘三鸣（各150血）。
  • 刘焜😋：干饭人，400血初始大体型；场上每5秒生成5个食物🍔（最多共存20个），吃到食物回血5并长大；普通碰撞扣10血；每10秒自动冲锋锁定最近的敌人高速撞过去，撞上扣30血。
  • 阵营：王艳、丁晓华、历史老师、赵丽娜为👩‍🏫老师阵营，其余角色为🧑‍🎓学生阵营；王艳召唤的家长只攻击学生。
